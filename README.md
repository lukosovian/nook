# Nook

Windows için ekranın üst ortasındaki çentikte yaşayan, yaşayan bir "Dynamic Island" ve küçük yardımcı.
Müzik, dosya rafı, pano, notlar, alarmlar, odak sayacı, göz/su molası, Gemini ile sohbet ve daha fazlası.

## Kurulum
[Releases](https://github.com/lukosovian/nook/releases/latest) sayfasından `Nook_x.y.z_x64-setup.exe` dosyasını indirip çalıştır.
Windows "bilgisayarınız korundu" derse **Ek bilgi → Yine de çalıştır**. İlk açılışta Nook kendini tanıtır.
Güncellemeler kendiliğinden gelir (Ayarlar › Sürüm).

## Geliştirme
Tauri 2 + React. `npm install`, sonra `npm run tauri dev`. Yeni sürüm: `.\release.ps1 "notlar"`.
